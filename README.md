# 🍽️ Taste Haven – Food & Restaurant Website

Welcome to **Taste Haven**, a modern and visually appealing food website designed to give users an enjoyable experience exploring delicious food, discovering menu items, and learning about a restaurant.

## 🌟 About the Project

Taste Haven is a restaurant-themed website that combines attractive design, a user-friendly interface, and a delightful food-inspired layout. The project aims to create an engaging online experience for food lovers through a clean design and interactive website elements.

## ✨ Features

- 🍕 **Attractive UI** – Clean, modern and visually appealing design.
- 🍽️ **Food Exploration** – Explore delicious food and menu items.
- 📱 **Responsive Design** – Designed to work across different screen sizes.
- 🎨 **Stylish Layout** – Beautiful colors, typography and visual elements.
- 🧭 **Easy Navigation** – Simple and user-friendly navigation.
- 💻 **Interactive Experience** – Engaging website elements for visitors.

## 🛠️ Technologies Used

- **HTML5** – Structure of the website.
- **CSS3** – Styling, layouts and responsive design.
- **JavaScript** – Interactive functionality.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Rajyasri1904/Taste-Haven-.git
```

### 2. Navigate to the project folder

```bash
cd Taste-Haven-
```

### 3. Run the website

Open the `index.html` file in your browser, or use the Live Server extension in VS Code.
